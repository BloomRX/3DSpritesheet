# Referências externas da marca Lia

Estes arquivos foram extraídos sem alterações de `docs/Lia.zip`, enviado pelo usuário. O ZIP continua preservado como fonte original.

- `00-PADRAO-DA-MARCA.md` — padrão de pastas, distribuição e armazenamento para apps Windows.
- `01-GUIA-APP-NOVO.md` — princípios de marca, consentimento e integração opcional com a Lia Waifu.
- `GLOSSARIO.md` — termos que não devem ser confundidos.

O material foi escrito como plano para apps novos e inclui trechos específicos de Python/PyInstaller. Para Lia Forge, que já existe em Electron/React e tem um launcher Python auxiliar, use `docs/lia-ecosystem-integration.md` como adaptação do projeto. Os exemplos do kit não provam que qualquer comportamento foi implementado ou testado no Windows.
