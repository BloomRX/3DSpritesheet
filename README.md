# Lia Forge — Game Asset Studio

Lia Forge é a ferramenta do ecossistema Lia voltada à organização e produção de assets para jogos.

Este arquivo descreve a identidade do produto; consulte o conteúdo efetivamente presente neste branch para confirmar o estado de implementação. Não presuma que funcionalidades de branches de trabalho já foram integradas.

## Padrões e documentação

- [`docs/BRAND-STANDARDS.md`](docs/BRAND-STANDARDS.md) — princípios comuns da marca Lia.
- `AGENTS.md` — regras de trabalho para agentes.
- `docs/` — documentação técnica e de produto presente neste branch.
